# Bundled fonts

`DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` are DejaVu fonts (version 2.37), taken from the
Matplotlib 3.11 wheel's `mpl-data/fonts/ttf` folder. They are embedded (subset) in PDF exports
and used to render SVG and PNG exports, so output looks the same on every computer and covers
Latin, Greek, and Cyrillic scripts, including Spanish, Portuguese, Haitian Creole, and Vietnamese.
