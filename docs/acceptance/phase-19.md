# Acceptance script: Phase 19 (policy and law; v1.0 hardening)

Run these prompts in Claude Desktop with the synthetic corpus (`fixtures/synthetic/data`) in the mounted folder and the `policy` and `core` toolsets enabled (for example `PHN_TOOLSETS=policy,core`). Record pass/fail and notes. Rows 1 to 27 cover the Phase 19 tools; rows 28 to 30 are the v1.0 hardening checks; run them with no profile and no `PHN_TOOLSETS` set (every toolset on), except row 29, which changes the profile on purpose. The threat model and the administrator guide are in `docs/security/threat-model.md` and `docs/admin-guide.md`.
