# Acceptance script: Phase 17 (grants and finance)

Run these prompts in Claude Desktop with the synthetic corpus (`fixtures/synthetic/data`) in the mounted folder and the `planning`, `leadership`, `equity`, and `core` toolsets enabled (the grant application prompt uses a community data tool from `equity`) (for example `PHN_TOOLSETS=planning,leadership,equity,core`). Record pass/fail and notes.

Rows 1 to 13 cover the grant tools and the `prepare_grant_application` prompt; 14 to 22 cover `build_program_budget` and `economic_evaluation_calculator`; 23 to 36 cover `analyze_health_department_budget` and `model_staffing_needs`.
