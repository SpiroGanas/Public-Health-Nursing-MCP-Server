## Changelog

- `track_ma_legislation` (POL-01, toolset `policy`): tracks Massachusetts bills of the 194th General Court (2025-2026) on 18 public health topics (or your title keywords, bill numbers, or a watchlist CSV) from the Legislature's public API (`malegislature.gov/api`, no key). For each bill it gives the stage (this project's reading of the history, by rules shown in the content file), the latest committee referral, hearing lines with the hearing date and days until it, the committee's reporting deadline, the last action with its date, and an excerpt of the bill text of 25 words or fewer with its citation, plus structured questions for the nurse's own analysis (it never says what a bill would do). It can save a watchlist to `/data/output`. Live (the 12 MB bill list cached for a day), then a dated bundled snapshot (822 bills, built 2026-11-13); it says which was used. Sponsor and amendment-author names are not returned.
- `monitor_federal_rules` (POL-03, toolset `policy`): watches the Federal Register API for proposed rules, final rules, and notices from CDC, CMS, HRSA, EPA, USDA, and HHS (also FDA, SAMHSA, ACF, FNS, FSIS, or any agency slug), with each comment deadline counted down against today's date (golden-tested against Python date arithmetic), an optional Regulations.gov cross-check (`PHN_REGULATIONS_GOV_API_KEY`, never shown), and a nine-section public comment outline (Word, `[NURSE: ...]` placeholders, filled from a field/value CSV, built from EPA's published tips for effective comments, quotations of 25 words or fewer). Live only: when the Federal Register cannot be reached it says LIVE DATA UNAVAILABLE and lists nothing.

## Content review

- `content/policy/ma_legislation_tracking.yaml` (pending; 2027-02-01): the API was called and read. Check (a) the **18 topic keyword lists** (this project's choices; edit them for your agency; they match titles only, so a bill that never uses the word is missed; "heat", "toxic", and "trauma" were dropped as too noisy), (b) the **stage rules** (this project's reading of 850 bills' history wording, medium confidence: for example "Accompanied a study order" is read as the end of a bill, "Reported favorably ... referred to the committee on House Ways and Means" as reported out; confirm against a few bills you know), and (c) the nine analysis questions (drafting aids). The Legislature's terms of use were not found in the API description.
- `snapshots/ma_legislation_194.json` (822 bills, retrieved 2026-11-13, built by `xtask/scripts/build_tracking_snapshots.py`): public records, one excerpt of 25 words or fewer per bill, sponsor and amendment-author names removed. Status is as of its date. The builder's `--check` verifies the file on disk (checksum, topic tags follow from titles, excerpt lengths); it does not re-download.
- `content/policy/federal_rules_tracking.yaml` (pending): federalregister.gov, regulations.gov, and api.regulations.gov were **blocked**, so nothing was verified against the live APIs. Agency slugs for EPA, HHS, and USDA come from the Federal Register's own open-source agency mapping (verified); **CDC, CMS, HRSA, FDA, SAMHSA, ACF, and FSIS slugs are from memory (confidence low)**; FNS appears in the same repository's data (medium). The comment outline arranges **EPA's** tips (page read 2026-11-12): confirm the nine sections suit your agency's habits, and that other agencies you comment to do not require a form. The countdown note's description of the 11:59 pm Eastern deadline is an observation from one recorded Regulations.gov response and is low confidence.

## Open items

- **Live adapters untested against the live services.** The Federal Register API and Regulations.gov were blocked (HTTP 403 on the proxy CONNECT). The parsers and URL builders were written from the Federal Register's open-source code (`usnationalarchives/federalregister-api-core`: serializers, search conditions, `agency mapping`, and recorded Regulations.gov v4 responses) and tested against local mock servers; `#[ignore]`d live tests exist (`cargo test -p phn-data -- --ignored`, `cargo test -p phn-tools --test phase19_tracking_mock -- --ignored`). Run them once on a network that reaches both hosts and fix any field or filter that differs. Regulations.gov is used only for the documented `filter[frDocNum]` lookup; search filters for it were not used because they could not be verified.
- **Network lessons.** `malegislature.gov` works: its Swagger document is at `/api/swagger/v1/swagger.json`; there is no search endpoint, and `/api/GeneralCourts/194/Documents` is about 12 MB (10 seconds uncompressed), so the tool caches it for a day and matches titles itself. `www.epa.gov/dockets/commenting-epa-dockets` works. `raw.githubusercontent.com`, `api.github.com`, and `github.com` clones work (useful for reading open-source API code when the API's own pages are blocked).
- **Leak-test collisions.** Sponsor names (public officials) and amendment authors' names in the Legislature's data collide with the seeded common surnames (Williams, Garcia, Moore, ...), so they are not returned. The snapshot's dates (2026-03-05, 2026-05-18, 2026-06-11, 2026-07-06) coincide with seeded birth dates of `growth_measurements.csv`; the leak rows for these tools do not use that file. A later tool that returns Legislature dates alongside `growth_measurements.csv` would trip the same match.
- **Titles only.** Bills are found by title words. Searching bill text needs the full bill documents (about 12 MB of titles; text for 9,000 bills is far larger) and was not attempted. A bill's hearing dates come from history lines, not from the hearings calendar (`/api/Hearings`, not used).
- **Stage is a heuristic.** The Legislature publishes no status field. The nurse should confirm the stage rules against bills she knows; sequential referrals (reported to Ways and Means) read as "reported out".
- **Decisions for the nurse.** Whether the topic list and the default agencies suit her agency; whether to add `agency_slugs` for her usual agencies once verified; whether a watchlist should also be mirrored by a scheduled check (not built).
- **Regulations.gov key.** A free api.data.gov key is read from `PHN_REGULATIONS_GOV_API_KEY`; it is added to the request URL only (never to the cache key, a citation, or a response; a test checks this). The client name is the server's generic user agent.
- **Disk.** Builds in this worktree used `CARGO_BUILD_JOBS=1`; the full `cargo test --workspace` was run in pieces (see the report).
