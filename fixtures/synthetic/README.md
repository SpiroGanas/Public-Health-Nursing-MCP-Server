# Synthetic test corpus

Everything in this folder is **fictional**. It exists so tests can prove that the privacy
guardrails work: the PHI detector must flag every identifier listed in
`seeded_identifiers.json`, and no tool may return any of those values unless the caller
explicitly asks for row-level data (and even then identifiers are masked).

| File | What it is |
|---|---|
| `data/line_list.csv` | 25-row outbreak line list with names, dates of birth, addresses, ZIP codes, phone numbers, email, SSNs, MRNs, MassHealth IDs, case IDs, and free-text notes. Two people are over 89. |
| `data/counts_by_town.csv` | Aggregate counts by town and year, with totals, for suppression tests. |
| `data/church_supper_outbreak.csv` | 60 attendees of a fictional church supper (34 ill with salmonellosis-like illness, onset dates and times, symptoms, 10 foods; stuffing is the vehicle), with names, phone numbers, and case IDs. Generated by a seeded script for Phase 3 tests. |
| `data/exclusion_letters.csv` | Mail-merge data (parent and student names). |
| `data/school_roster.csv` | 24-student school immunization roster (student IDs, names, dates of birth, grade, dose dates by vaccine, exemptions) with complete, incomplete, exempt, and invalid-date records, for the school requirements check. |
| `data/school_screenings.csv` | 28-student screening roster (student IDs, names, dates of birth, sex, grade, home language, parent names and phones, vision, hearing, postural, BMI height and weight, kindergarten vision certificate) for the Phase 7 screening tracker and annual report. |
| `data/school_absence_log.csv` | One row per absent student-day for two fictional schools over 26 school days (student IDs and names, grade, reason), with a stomach-illness spike at one school in the last two days, for the absenteeism monitor. |
| `data/health_office_visits.csv` | A 2025-2026 health office visit log (student IDs and names, grade, reason, disposition, 911 type, head injury) for the annual report. |
| `data/concussion_log.csv` | Six head injury records (student and parent names, IDs, parent emails, notification and clearance dates) for the concussion tracker. |
| `data/health_plan_students.csv` | Five students needing health plans (names, IDs, dates of birth, parent names and phones, conditions) for the health plan builder. |
| `generators/phase7_school_fixtures.py` | Seeded script that wrote the five Phase 7 files above and their entries in `seeded_identifiers.json`. |
| `data/phq9_screens.csv` | 8 PHQ-9 screens (q1-q9) with client IDs, names, dates of birth, and phone numbers, two with item 9 above zero and one with a missing item, for `score_mental_health_screen` file mode (Phase 10). |
| `data/protective_report_details.csv` | 2 elder protective services report rows (names, addresses, phones, caretaker, observations with an embedded phone) for local fill (Phase 10). |
| `data/proxy_details.csv` | 3 health care proxy rows (principal, agent, witnesses, phones, Spanish/Portuguese/blank language) for local fill (Phase 10). |
| `data/growth_measurements.csv` | 20 child-visit rows for the growth calculator (record IDs, names, birth and measurement dates, sex, weight, height, head circumference, gestational age, parent phone), including a preterm infant, an extreme value, and two rows that cannot be scored (missing sex, invalid birth date). Generated from the WHO and CDC tables with a fixed seed (Phase 8). |
| `data/51a_notes.txt` | A nurse's notes for a 51A written report in "Field name: value" lines (child, caregiver, address, phones, birth date, observations), for the local-fill draft test (Phase 8). |
| `data/tb_contacts.csv` | 12 contacts of a fictional infectious TB case (contact IDs, names, phone numbers, age, household, setting, last exposure, test results), for the TB contact investigation planner (Phase 9). |
| `data/hrsn_screenings.csv` | 15 fictional AHC health-related social needs screenings (client names, MRNs, dates of birth, site, answers to items 1-10), for the HRSN screening tool (Phase 9). |
| `data/resources/community_resources.csv` | A fictional community resource directory (organizations only, 555-01xx phone numbers) for find_community_resources (Phase 9). |
| `data/postvention_details.csv` | One row of fictional school notice details (school, student, principal, counselor, spokesperson, phones) for filling the postvention templates locally (Phase 11). |
| `data/client_note.txt` | A free-text home visit note with embedded identifiers. |
| `data/shelter_registrations.csv` | 12 fictional shelter registrants (names, dates of birth, phones, addresses, emails, preferred language) with CMIST intake answers, for the Phase 12 shelter intake tool. |
| `data/cooling_centers.csv` | Four cooling centers with a fictional after-hours contact person, cell phone, and email that must never be returned (Phase 12 heat planner). |
| `data/casper_results.csv` | 198 fictional CASPER interviews in 30 clusters (7, or 5 in every fifth cluster) with structure, damage, generator, and medication answers, plus household addresses and callback phones that must never be returned. |
| `data/staff_roster.csv` | 12 fictional health department and partner staff (names, ICS positions, agencies, work and cell phones, emails, radio call signs) for the Phase 13 ICS, COOP, and exercise tools. Names may appear in chat only when the caller passes them; nothing read from this file may be returned. |
| `data/exercise_feedback.csv` | 14 fictional HSEEP Participant Feedback Forms (names, emails, agency, exercise role, eight 1-5 ratings, and free-text comments) for the Phase 13 after-action report tool, which may return only suppressed aggregates. |
| `data/ejscreen_ma_extract.csv` | 24 block group rows shaped like an archived EPA EJScreen 2.3 extract (22 real Lowell 2020 block group codes, two elsewhere) with made-up percentiles and a fictional reviewer name and email that must never be returned (Phase 14 EJ screen). |
| `data/bp_screening_log.csv` | 32 fictional blood pressure screening rows (participant ID, name, address, town, phone, age, two readings, referral status), including a 15-year-old and a row with no reading, for `community_bp_screening_toolkit` log mode (Phase 15). |
| `data/prediabetes_responses.csv` | 26 fictional Prediabetes Risk Test responses (names, phone numbers, age, sex, family history, blood pressure, activity, height, weight), one row missing an answer, for `diabetes_prevention_finder` (Phase 15). |
| `data/asthma_plans.csv` | 3 fictional people for asthma action plans (names, dates of birth, doctor, phone numbers, best peak flow, medicines and doses, triggers) for `asthma_home_assessment` (Phase 15). |
| `data/focus_group_transcript.txt` | A fictional community focus group transcript with five participants and planted identifiers (see `seeded_identifiers.json`), for `analyze_qualitative_data` (Phase 15). |
| `data/key_informant_interview.txt` | A fictional key informant interview transcript (a food pantry director) for `analyze_qualitative_data` (Phase 15). |
| `data/participant_names.txt` | The fictional participant names for the transcripts, one per line, used to remove names (Phase 15). |
| `data/address_list.csv` | 31 fictional client addresses (client ID, last and first name, phone, home address, city, ZIP) for `geocode_and_aggregate_addresses`; seeded identifiers are in `seeded_identifiers.json`. Generator `generators/phase15_geo_fixture.py` (Phase 15). |
| `data/program_metrics.csv` | 12 months of fictional program results (clients enrolled, sessions held, participants screened and eligible, housing referrals) with a contact person, cell phone, and email that must never be returned, for `track_program_performance` (Phase 16). |
| `data/program_outcomes_long.csv` | 12 rows of fictional program outcomes by quarter in long layout (outcome, value, denominator) with a reporter name and email that must never be returned (Phase 16). |
| `data/study_abstract.txt` | A fictional abstract of a cluster randomized trial with a fictional corresponding author, for `appraise_evidence` (Phase 16). |
| `data/qi_clinic_measure.csv` | 20 fictional months of children seen and up to date, with a contact person, cell phone, and email, for `plan_quality_improvement`. Generator `generators/phase16_qi_fixture.py` (Phase 16). |
| `data/synthetic_nofo.docx` | A synthetic notice of funding opportunity (deadline 2027-02-26, page limits, five scoring criteria, attachments) for `analyze_funding_announcement`. Generator `generators/phase17_grants_fixtures.py` (Phase 17). |
| `data/synthetic_rfr.pdf` | A synthetic Massachusetts request for response (7 pages, numbered criteria, questions and response dates, a procurement contact that must never be returned). Same generator (Phase 17). |
| `data/program_budget_lines.csv` | 8 fictional program budget lines (category, item, funding, salary, effort, quantity, unit cost, years, subaward) for `build_program_budget` (Phase 17). |
| `data/health_dept_budget.csv` | 17 fictional health department budget lines (account, category, type, budgeted, year to date, encumbrances, positions) with vendor and employee names, a vendor email, and a phone that must never be returned, for `analyze_health_department_budget` (Phase 17). |
| `data/health_dept_budget_small.csv` | A 6-line version of the budget with fewer than three positions behind the personnel row, for the personnel privacy rule (Phase 17). |
| `data/health_dept_ledger_monthly.csv` | 32 fictional ledger rows by month (month, account, category, type, budgeted, actual, encumbrances) with vendor and employee columns, for the monthly layout and run-rate forecast (Phase 17). |
| `data/staffing_volumes.csv` | 4 fictional service volumes with minutes per unit and a contact person and email that must never be returned, for `model_staffing_needs` (Phase 17). |
| `data/fphs_assessment.csv` | 6 fictional rows of a filled self-assessment worksheet (ID, standard, status, delivered by, priority) with a lead person, phone, email, and notes that must never be returned, for `assess_foundational_public_health_services` (Phase 18). |
| `data/workforce_ratings.csv` | 48 fictional competency self-rating rows (staff code, tier, domain, competency, rating) with a supervisor name and email that must never be returned, for `assess_workforce_competencies`. Generator `crates/phn-server/tests/fixtures/phase18_workforce/generate.py` (Phase 18). |
| `data/workforce_credentials.csv` | 16 fictional credential rows (staff code, position, hire date, credential, completed date) with a supervisor name and phone that must never be returned. Same generator (Phase 18). |
| `data/board_meeting_notes.txt` | Fictional board of health meeting notes for 2026-12-07 (members present, motions, votes, an executive session item, and a resident's name, address, and phone) for the minutes draft (Phase 18). |
| `data/policies/` | Two short agency policies; one contains an example SSN that must never be returned. |
| `seeded_identifiers.json` | Every seeded identifier value, its kind, and its file. |

Values were chosen so they cannot belong to real people: phone numbers use the 555-01xx range
reserved for fiction, email addresses use `example.org`/`example.com`, and SSNs start with 9,
which the Social Security Administration never assigns.
